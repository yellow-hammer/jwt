| `JWT` | `Подписать(ПолезнаяНагрузка, Секрет, Параметры = Неопределено)` | `Строка` |
| `JWT` | `Проверить(Токен, Секрет, Параметры = Неопределено)` | `JwtVerificationResult` |
| `JWT` | `ПроверитьАсимметричный(Токен, Проверяющий, Параметры = Неопределено)` | `JwtVerificationResult` |
| `JWT` | `Разобрать(Токен)` | `Структура` |
| `JWT` | `ПоддерживаемыеАлгоритмы()` | `Массив` |
| `JWT` | `ТекущееВремя()` | `Число` |

| `JwtVerificationResult` | `ВыброситьЕслиНеВалиден()` | - |

## Свойства результата проверки

| Свойство | Тип | Содержимое |
|---|---|---|
| `Валиден` | `Булево` | Подпись верна и все проверки пройдены |
| `ПолезнаяНагрузка` | `Соответствие` | Утверждения; заполнено только для валидного токена |
| `Заголовок` | `Соответствие` | Заголовок JOSE, если его удалось прочитать |
| `КодОшибки` | `Строка` | Машиночитаемый код отказа |
| `Ошибка` | `Строка` | Человекочитаемое описание отказа |

## Алгоритмы

| Алгоритм | Хеш | Замечание |
|---|---|---|
| `HS256` | SHA-256 | По умолчанию |
| `HS384` | SHA-384 | |
| `HS512` | SHA-512 | |

Алгоритм `none` запрещён всегда. Подписывать библиотека умеет только этими тремя алгоритмами; `RS256` она принимает
в проверке через `ПроверитьАсимметричный`, где подпись проверяет внешний объект - например `ПроверяющийJWS`
из пакета [jwt-verify](https://github.com/oscript-library/jwt-verify).

## Внутренние классы

Не входят в публичный контракт и могут меняться без изменения мажорной версии.

| Класс | Назначение |
|---|---|
| `JwtHandler` | Сборка, подпись и проверка токена |
| `Base64Url` | Кодирование base64url без выравнивания (RFC 7515, приложение C) |
