# Класс `JwtVerificationResult`

Результат проверки токена, который возвращают [`JWT.Проверить`](../Модули/JWT.md#проверить)
и [`JWT.ПроверитьАсимметричный`](../Модули/JWT.md#проверитьасимметричный).

Проверка никогда не выбрасывает исключение: любой отказ описывается кодом и текстом ошибки. Это позволяет обрабатывать
невалидные токены как обычную ветку логики, а не как аварию.

Исходник: `src/Классы/JwtVerificationResult.os`

## Свойства

| Свойство | Тип | Содержимое |
|---|---|---|
| `Валиден` | `Булево` | `Истина`, если подпись верна и все проверки пройдены |
| `ПолезнаяНагрузка` | `Соответствие` | Разобранные утверждения. Для невалидного токена `Неопределено` |
| `Заголовок` | `Соответствие` | Разобранный заголовок JOSE, если его удалось прочитать |
| `КодОшибки` | `Строка` | Машиночитаемый код отказа. Для валидного токена пустая строка |
| `Ошибка` | `Строка` | Человекочитаемое описание отказа |

Полезная нагрузка невалидного токена не возвращается намеренно: непроверенные данные невозможно использовать по ошибке.
Заголовок, наоборот, заполняется и при отказе, если разбор дошёл до него, - это помогает понять причину.

## Методы

| Метод | Возвращает | Назначение |
|---|---|---|
| [`Утверждение`](#утверждение) | `Произвольный` | Значение утверждения со значением по умолчанию |
| [`ВыброситьЕслиНеВалиден`](#выброситьеслиневалиден) | - | Превратить отказ в исключение |

Методы `ЗаполнитьУспех` и `ЗаполнитьОтказ` предназначены для внутреннего использования обработчиком токенов.

## Утверждение

```bsl
Функция Утверждение(Знач Имя, Знач ЗначениеПоУмолчанию = Неопределено) Экспорт
```

Возвращает утверждение валидного токена. Для невалидного результата и для отсутствующего утверждения возвращается
значение по умолчанию, поэтому проверять `Валиден` перед каждым обращением не нужно.

**Параметры**

| Параметр | Тип | Назначение |
|---|---|---|
| `Имя` | `Строка` | Имя утверждения, например `"sub"` |
| `ЗначениеПоУмолчанию` | `Произвольный` | Что вернуть, если утверждения нет |

**Возвращаемое значение**

`Произвольный` - значение утверждения.

```bsl
Роль = Результат.Утверждение("role", "guest");
Осталось = Результат.Утверждение("exp", 0) - JWT.ТекущееВремя();
```

## ВыброситьЕслиНеВалиден

```bsl
Процедура ВыброситьЕслиНеВалиден() Экспорт
```

Выбрасывает исключение, если токен не прошёл проверку. Удобно там, где невалидный токен действительно аварийная
ситуация: в фоновом задании или при межсервисном вызове со своим же токеном.

Текст исключения: `JWT: <описание> (<код>)`.

```bsl
JWT.Проверить(Токен, Секрет, Параметры).ВыброситьЕслиНеВалиден();

// Дальше можно работать: сюда попадаем только с валидным токеном
```

## Коды отказа

| Код | Причина |
|---|---|
| `MALFORMED` | Токен не разбирается: не три части, битый base64url или не JSON |
| `INVALID_SIGNATURE` | Подпись не соответствует содержимому или ключу |
| `TOKEN_EXPIRED` | Истёк `exp` |
| `TOKEN_NOT_ACTIVE` | Не наступил `nbf` |
| `MISSING_CLAIM` | Отсутствует утверждение, объявленное обязательным |
| `INVALID_ISSUER` | `iss` отсутствует или не совпал с ожидаемым |
| `INVALID_AUDIENCE` | `aud` отсутствует или не совпал с ожидаемым |
| `INVALID_SUBJECT` | `sub` не совпал с ожидаемым |
| `ALGORITHM_NOT_ALLOWED` | Алгоритм `none` либо алгоритм вне списка разрешённых |
| `UNSUPPORTED_ALGORITHM` | Алгоритм неизвестен библиотеке |
| `UNSUPPORTED_CRITICAL_HEADER` | Присутствует заголовок `crit` |
| `INVALID_TYPE` | `typ` не совпал с ожидаемым |

Ещё четыре кода возможны только при асимметричной проверке, где подпись проверяет внешний объект:

| Код | Причина |
|---|---|
| `KEY_ID_MISSING` | В заголовке нет `kid`: выбрать ключ нечем |
| `KEY_NOT_FOUND` | Ключ с таким `kid` недоступен - ключи не загрузились либо издатель их не публикует |
| `VERIFIER_FAILED` | Проверяющий подписи упал с исключением |
| `VERIFICATION_FAILED` | Проверяющий отказал по причине, которой нет в этом перечне |

Коды машиночитаемы, поэтому решение принимается таблицей, а не разбором текста. Запасная ветка обязательна: перечень
может пополниться в новой версии.

```bsl
Ответы = Новый Соответствие();
Ответы.Вставить("TOKEN_EXPIRED", 401);
Ответы.Вставить("INVALID_AUDIENCE", 403);

КодСостояния = Ответы[Результат.КодОшибки];
КодСостояния = ?(КодСостояния = Неопределено, 401, КодСостояния);
```
