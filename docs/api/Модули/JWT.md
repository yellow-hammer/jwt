# Модуль `JWT`

Фасад библиотеки: подпись токена, проверка подписи и утверждений, разбор без проверки, справка об алгоритмах и времени.

Модуль держит один обработчик на процесс и делегирует вызовы ему. Состояния между вызовами нет.

Исходник: `src/Модули/JWT.os`

## Методы

| Метод | Возвращает | Назначение |
|---|---|---|
| [`Подписать`](#подписать) | `Строка` | Токен в компактной сериализации JWS |
| [`Проверить`](#проверить) | `JwtVerificationResult` | Проверка подписи и утверждений |
| [`ПроверитьАсимметричный`](#проверитьасимметричный) | `JwtVerificationResult` | Утверждения чужого токена, подпись которого проверяет внешний объект |
| [`Разобрать`](#разобрать) | `Структура` | Заголовок и нагрузка **без проверки подписи** |
| [`ПоддерживаемыеАлгоритмы`](#поддерживаемыеалгоритмы) | `Массив` | `HS256`, `HS384`, `HS512` |
| [`ТекущееВремя`](#текущеевремя) | `Число` | Текущее время в формате NumericDate |

## Подписать

```bsl
Функция Подписать(Знач ПолезнаяНагрузка, Знач Секрет, Знач Параметры = Неопределено) Экспорт
```

Создаёт подписанный токен.

**Параметры**

| Параметр | Тип | Назначение |
|---|---|---|
| `ПолезнаяНагрузка` | `Структура`, `Соответствие` | Утверждения (claims) |
| `Секрет` | `Строка`, `ДвоичныеДанные` | Общий секрет для HMAC, пустым быть не может |
| `Параметры` | `Структура`, `Соответствие` | См. [Параметры подписи](#параметры-подписи) |

**Возвращаемое значение**

`Строка` - токен в компактной сериализации JWS: три части через точку.

**Исключения**

| Условие | Сообщение |
|---|---|
| Неизвестный алгоритм | `JWT: алгоритм %1 не поддерживается` |
| Пустой секрет | `JWT: секрет не может быть пустым` |
| Утверждение задано и в нагрузке, и параметром | `JWT: утверждение %1 задано и в полезной нагрузке, и параметром %2` |

```bsl
Нагрузка = Новый Структура("sub, role", "user-42", "admin");

Параметры = Новый Структура();
Параметры.Вставить("ВремяЖизни", 3600);
Параметры.Вставить("Издатель", "auth.example.com");
Параметры.Вставить("Аудитория", "dashboard");

Токен = JWT.Подписать(Нагрузка, Секрет, Параметры);
```

### Параметры подписи

| Параметр | Тип | Действие |
|---|---|---|
| `Алгоритм` | `Строка` | `HS256` (по умолчанию), `HS384`, `HS512` |
| `ВремяЖизни` | `Число` | Срок жизни в секундах, заполняет `exp` |
| `ДействителенЧерез` | `Число` | Задержка вступления в силу, заполняет `nbf` |
| `Издатель` | `Строка` | Заполняет `iss` |
| `Аудитория` | `Строка`, `Массив` | Заполняет `aud` |
| `Субъект` | `Строка` | Заполняет `sub` |
| `Идентификатор` | `Строка` | Заполняет `jti` |
| `ДобавлятьВремяВыпуска` | `Булево` | Заполнять `iat`, по умолчанию `Истина` |
| `ИдентификаторКлюча` | `Строка` | Заголовок `kid` |
| `ТипТокена` | `Строка` | Заголовок `typ`, по умолчанию `JWT` |
| `ДополнительныеЗаголовки` | `Структура`, `Соответствие` | Прочие заголовки JOSE |
| `ТекущееВремя` | `Число` | Подменяет текущее время; нужно в тестах |

## Проверить

```bsl
Функция Проверить(Знач Токен, Знач Секрет, Знач Параметры = Неопределено) Экспорт
```

Проверяет подпись и утверждения токена. Функция не выбрасывает исключений: причина отказа возвращается в результате,
поэтому невалидный токен обрабатывается как обычная ветка логики.

Порядок проверок: разбор структуры, заголовок (`alg`, `crit`, `typ`), подпись, разбор нагрузки, утверждения.

**Параметры**

| Параметр | Тип | Назначение |
|---|---|---|
| `Токен` | `Строка` | Токен в компактной сериализации JWS |
| `Секрет` | `Строка`, `ДвоичныеДанные` | Общий секрет для HMAC |
| `Параметры` | `Структура`, `Соответствие` | См. [Параметры проверки](#параметры-проверки) |

**Возвращаемое значение**

[`JwtVerificationResult`](../Классы/JwtVerificationResult.md) с полями `Валиден`, `ПолезнаяНагрузка`, `Заголовок`,
`КодОшибки`, `Ошибка`.

```bsl
Результат = JWT.Проверить(Токен, Секрет);

Если Результат.Валиден Тогда
	Роль = Результат.ПолезнаяНагрузка["role"];
Иначе
	Логировать(Результат.КодОшибки, Результат.Ошибка);
КонецЕсли;
```

### Параметры проверки

| Параметр | Тип | Действие |
|---|---|---|
| `Алгоритмы` | `Массив` | Разрешённые алгоритмы, по умолчанию все три |
| `ПроверятьСрок` | `Булево` | Проверять `exp` и `nbf`, по умолчанию `Истина` |
| `Допуск` | `Число` | Допустимое расхождение часов в секундах |
| `Издатель` | `Строка`, `Массив` | Ожидаемое `iss`; массив означает «любое из» |
| `Аудитория` | `Строка`, `Массив` | Ожидаемое `aud`; массив означает «любое из» |
| `Субъект` | `Строка` | Ожидаемое `sub` |
| `ТипТокена` | `Строка` | Ожидаемый заголовок `typ` |
| `ТребоватьСрок` | `Булево` | Считать отсутствие `exp` ошибкой |
| `ТребоватьДействителенС` | `Булево` | Считать отсутствие `nbf` ошибкой |
| `ТребоватьВремяВыпуска` | `Булево` | Считать отсутствие `iat` ошибкой |
| `ТекущееВремя` | `Число` | Подменяет текущее время; нужно в тестах |

Список алгоритмов задаёт проверяющая сторона: значению `alg` из самого токена не доверяем, поэтому подмена алгоритма
не проходит. Алгоритм `none` запрещён всегда, даже если он указан в списке.

```bsl
Параметры = Новый Структура();
Параметры.Вставить("Издатель", "auth.example.com");
Параметры.Вставить("Аудитория", "dashboard");
Параметры.Вставить("Допуск", 30);
Параметры.Вставить("ТребоватьСрок", Истина);

Результат = JWT.Проверить(Токен, Секрет, Параметры);
Результат.ВыброситьЕслиНеВалиден();
```

## ПроверитьАсимметричный

```bsl
Функция ПроверитьАсимметричный(Знач Токен, Знач Проверяющий, Знач Параметры = Неопределено) Экспорт
```

Проверяет утверждения токена, подпись которого проверяет внешний объект. Нужна для токенов, выпущенных чужой
стороной: общего секрета с ней нет, а есть открытые ключи издателя.

Разделение труда здесь не формальность. Чтобы доказать происхождение токена, нужны JWKS издателя и RSA - этим
занимается [jwt-verify](https://github.com/oscript-library/jwt-verify). Чтобы решить, годится ли токен этому
сервису, нужны ожидаемые `iss`, `aud` и `sub`, о которых проверяющий подписи знать не может.

**Параметры**

| Параметр | Тип | Назначение |
|---|---|---|
| `Токен` | `Строка` | Токен в компактной сериализации JWS |
| `Проверяющий` | `Произвольный` | Объект с методом `Проверить(Токен)`, например `ПроверяющийJWS` |
| `Параметры` | `Структура`, `Соответствие` | См. [Параметры проверки](#параметры-проверки) |

Проверяющим годится любой объект, чей метод `Проверить` возвращает структуру с полями `Успех`, `Код`, `Сообщение`,
`Алгоритм`, `Заголовок` и `Клеймы`. Поэтому зависимости времени выполнения у библиотеки нет: пакет проверки подписи
ставит и создаёт вызывающая сторона.

Параметр `Алгоритмы` здесь **сужает** белый список проверяющего, а не задаёт его: какие алгоритмы вообще
допустимы, решает тот, кто проверяет подпись. Сроки действия проверяются повторно, уже по часам и допуску
принимающей стороны.

**Возвращаемое значение**

[`JwtVerificationResult`](../Классы/JwtVerificationResult.md) - тот же класс, что и у симметричной проверки.
Коды отказа чужой библиотеки переведены в общий словарь, поэтому прикладной код разбирает исход одинаково.

| Код проверяющего | Код результата |
|---|---|
| `bad_signature` | `INVALID_SIGNATURE` |
| `expired` / `not_yet_valid` | `TOKEN_EXPIRED` / `TOKEN_NOT_ACTIVE` |
| `exp_missing` | `MISSING_CLAIM` |
| `kid_missing` / `key_not_found` | `KEY_ID_MISSING` / `KEY_NOT_FOUND` |
| `alg_not_allowed` | `ALGORITHM_NOT_ALLOWED` |
| `unsupported_header` | `UNSUPPORTED_CRITICAL_HEADER` |
| `malformed`, `malformed_claim` | `MALFORMED` |
| прочее | `VERIFICATION_FAILED` |

Исключение внутри проверяющего наружу не выходит: оно превращается в отказ с кодом `VERIFIER_FAILED`. Единственное
исключение, которое функция бросает, - отсутствие проверяющего: это ошибка вызова, а не свойство токена.

```bsl
#Использовать jwt-verify

Проверяющий = Новый ПроверяющийJWS(Новый КэшJWKS("https://token.actions.githubusercontent.com"));

Параметры = Новый Структура();
Параметры.Вставить("Издатель", "https://token.actions.githubusercontent.com");
Параметры.Вставить("Аудитория", "https://hub.example.com");

Результат = JWT.ПроверитьАсимметричный(Токен, Проверяющий, Параметры);

Если Результат.Валиден Тогда
	Репозиторий = Результат.Утверждение("repository");
КонецЕсли;
```

## Разобрать

```bsl
Функция Разобрать(Знач Токен) Экспорт
```

Разбирает токен **без проверки подписи**.

Полученным данным нельзя доверять: любой может подменить содержимое токена. Метод нужен для диагностики и для чтения
`kid` перед выбором ключа проверки.

**Параметры**

| Параметр | Тип | Назначение |
|---|---|---|
| `Токен` | `Строка` | Токен в компактной сериализации JWS |

**Возвращаемое значение**

`Структура` с полями `Заголовок` и `ПолезнаяНагрузка`, оба `Соответствие`.

```bsl
Содержимое = JWT.Разобрать(Токен);

// Выбор ключа по kid, после чего обязательна полная проверка
Ключ = Ключи[Содержимое.Заголовок["kid"]];
Результат = JWT.Проверить(Токен, Ключ);
```

## ПоддерживаемыеАлгоритмы

```bsl
Функция ПоддерживаемыеАлгоритмы() Экспорт
```

Список алгоритмов, которые понимает библиотека.

**Возвращаемое значение**

`Массив` строк: `HS256`, `HS384`, `HS512`.

```bsl
Сообщить(СтрСоединить(JWT.ПоддерживаемыеАлгоритмы(), ", "));   // HS256, HS384, HS512
```

## ТекущееВремя

```bsl
Функция ТекущееВремя() Экспорт
```

Текущее время в формате NumericDate (RFC 7519, раздел 2): секунды, прошедшие с `1970-01-01T00:00:00Z`. Тем же значением
библиотека заполняет `iat` и отсчитывает `exp`.

**Возвращаемое значение**

`Число` - метка времени.

```bsl
Осталось = Результат.Утверждение("exp") - JWT.ТекущееВремя();
```
